# Loon — iPhone PWA prototype

Это стартовый фронтенд-прототип. Сейчас в нём работают:
- переключение вкладок: Чаты / Контакты / Интересное / Настройки;
- открытие тестового чата и отправка сообщений в интерфейсе;
- поиск по демонстрационному списку чатов;
- установка на экран iPhone как веб-приложение.

## Как открыть на iPhone
1. Разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Откройте ссылку в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Важно
Это визуальный прототип: сообщения пока не отправляются другим людям, нет регистрации, сервера, базы данных и push-уведомлений. Следующий этап — подключение backend и реальной авторизации.
