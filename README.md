# Loon — iPhone PWA prototype

Стартовый фронтенд-прототип мессенджера для iPhone.

## Сейчас работает
- нижняя навигация: Чаты / Контакты / Интересное / Настройки;
- открытие демонстрационных чатов;
- отправка тестовых сообщений с сохранением на этом устройстве через localStorage;
- поиск по демонстрационным чатам;
- установка на экран «Домой» в Safari в режиме standalone;
- базовый офлайн-кэш через Service Worker.

## Установка на iPhone
1. Разместите проект на HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Откройте сайт в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Ограничения прототипа
Это пока интерфейсный MVP. Сообщения сохраняются только локально на устройстве и не доставляются другим людям. Регистрация, сервер, синхронизация между устройствами, push-уведомления и реальная система контактов будут отдельными этапами разработки.
